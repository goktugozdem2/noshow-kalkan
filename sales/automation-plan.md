# NoShow Kalkanı — Tam Otomatik Gelir Döngüsü

## Çalışan otomasyon

1. GitHub Pages landing organik/soğuk trafik alır.
2. Ziyaretçi ROI değerlerini girer.
3. Tarayıcıda anında haftalık/aylık kurtarma hesabı oluşur.
4. Kullanıcı tek tıkla GitHub issue olarak takip edilebilir pilot talebi açar.
5. Public teklif sayfası self-serve okunur.
6. Günlük cron yeni lead/SEO/satış asseti üretmeye devam eder.

## Şu an credential gerektiren ama eksik olan tam otomasyon parçaları

- Ödeme alma: Stripe/LemonSqueezy/Gumroad/iyzico token yok.
- E-posta/WhatsApp gönderimi: Resend/SendGrid/Mailgun/WhatsApp Business token yok.
- Sosyal otomatik paylaşım: xurl kurulu ama X app/auth yok.
- Vercel serverless env/deploy: Vercel auth/token yok.

## Blokersız yapılan yaklaşım

Ödeme/outbound credential gelmeden para alma tamamen kapalı değildir ama otomatik ödeme tahsilatı yapılamaz. Bu yüzden funnel self-serve talep + proposal + ROI + GitHub issue kayıt yoluna çekildi. Credential eklenirse aynı akış ödeme linki ve otomatik bildirimle tamamlanır.
